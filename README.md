# Cinematic Personal Intro

Build a stunning personal introduction website with a cinematic animated opening. Use a bold futuristic aesthetic with pink, blue, purple, and red gradients, floating/glitching typography, words flying in, smooth transitions, interactive elements, and responsive design for mobile and desktop. Make it feel polished, immersive, and stylish. Start with a strong animated hero intro and sections for About, Interests, and Contact. Use tasteful motion, excellent typography, and high-quality visual composition. Keep content editable and use placeholder contact links rather than inventing personal details.
